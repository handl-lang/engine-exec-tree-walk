# Reference

## Public API

| item | what it is |
|---|---|
| value shapes | tagged JSON pair `__pair__` and friends — the values combinators operate on |
| `EvalEngine` impl | the `engine-exec` contract |
| handler support | resumable `handle`/`perform` via the shared journal keys (ADR-0158) |

## Crate

| crate | role |
|---|---|
| `hnl-engine-exec-tree-walk` | engine implementation |

## Build and test

```bash
cargo build     # sibling [patch] tables resolve deps from ../<repo>
cargo test      # cargo test
```

Dependencies are git deps on `branch = "main"`; locally the `[patch]` tables
point at sibling checkouts (regenerated by `host/scripts/dev-link.sh`).
